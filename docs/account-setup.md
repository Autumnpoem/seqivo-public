# 序程账号接入指南

[English](account-setup.en.md) | 简体中文

适用流程：v0.4.x · 文档整理：2026-10-31

账号仅用于可选的 Hub 远程功能；刚安装桌面版、只查看本地项目进度时无需注册。完整本地流程见 [README](../README.md)。

本文使用 `https://board.example.com` 作为示例地址。请将它替换为服务维护者提供的真实 HTTPS 地址；也可以使用已配置有效证书的公网 IP 地址。

**已有空间和任务：**按第 2 节，用原管理员令牌进入并为原空间设置账号，然后在手机登录。原来已连接的桌面程序无需重新配对。

**第一次使用、没有旧任务：**打开真实服务器网址，点击「注册」，填写用户名和至少 12 位密码，点击「创建账号」。注册会创建独立的空空间；然后按第 4 节连接项目电脑，第 3 节登录手机。填写规则见第 2.3 节。

## 1. 先分清要用哪个账号

| 名称 | 用途 | 在哪里使用 |
|---|---|---|
| 序程用户名和密码 | 登录自己的项目空间 | 序程网页；桌面程序的「手机连接」 |
| 序程管理员令牌 | 进入现有空间，首次为它设置账号 | 网页「其他连接方式」→「访问令牌」 |
| 一次性配对码 | 给指定手机或电脑授权，可限定项目和权限 | 手机网页或桌面程序的配对入口 |
| Codex 登录账号 | 让项目电脑上的 Codex 执行任务 | 电脑上的 Codex 工具；序程账号不能代替它 |
| GitHub 账号 | 访问源码仓库、协作开发 | GitHub；仓库邀请不会自动创建序程账号 |
| 服务器 root 账号 | 管理服务器系统 | 服务器管理工具；接入序程时不用填写 |

序程当前使用**用户名登录**，没有邮箱登录、邮箱验证码或找回密码功能。不要把邮箱地址当作序程用户名。

## 2. 第一次：为你现有的空间设置账号

这一步在 **电脑浏览器**操作。它会保留已有项目、任务及设备连接。

### 2.1 找到原管理员令牌

原管理员令牌由部署该空间的维护者保管。自行部署时，初次运行 `bootstrap` 会输出对应令牌文件的位置；部署步骤见 [Hub 部署指南](deployment.md)。使用创建原空间时保存的令牌，不要为找令牌而重新创建空间。

维护者在自己的设备上打开对应令牌文件，复制完整的一行内容，再按下一节登录。普通使用者无需取得管理员令牌，可直接注册自己的空间，或让空间拥有者生成限定权限的配对码。

此令牌相当于当前空间的管理员凭据，请勿提交到 GitHub、发到群聊或与普通协作者共享。仓库不包含任何可直接使用的管理员令牌。

### 2.2 用令牌进入原空间

1. 在电脑浏览器打开 [序程网页](https://board.example.com/)。
2. 在登录页面展开 **「其他连接方式」**。
3. 点击 **「访问令牌」**。
4. 粘贴刚才复制的令牌，点击 **「进入看板」**。
5. 确认能看到原来的项目，包括项目名称及已有任务。

**如果网页已经显示原来的项目，可以直接继续下一步。** 如果已登录的是另一个空空间，先到「账号」退出，再按上述步骤进入原空间。

### 2.3 设置用户名和密码

1. 在网页导航中点击 **「账号」**。
2. 找到 **「为当前空间设置账号」**。
3. 填写自己想用的用户名和新密码。
4. 点击 **「绑定当前空间」**。

填写规则：

| 项目 | 规则与例子 |
|---|---|
| 用户名 | 3–40 位，以英文字母或数字开头，可含字母、数字、下划线、句点、短横线。例如 `myaccount`；以实际可用为准。建议使用小写。 |
| 密码 | 12–128 个字符，由你自己设置并保存；请勿共享。 |

**成功标志：**出现「当前空间已绑定账号，已有项目和任务会保留」，账号页显示「当前登录：你的用户名」。回到「任务清单」还能看到原来的任务。

如果已经显示你自己的用户名，说明账号已设置，直接用它在手机登录即可。每个空间只能绑定一个账号；已绑定后不要重复创建。

> 「注册」会新建一个独立的空空间。你现在要保留旧任务，应使用「绑定当前空间」。其他首次使用、没有旧任务的人可以在首页直接注册自己的账号。

## 3. 手机：用同一账号访问任务

手机暂时不需要安装 App，也不需要和电脑在同一个 Wi-Fi 下。

1. 用手机浏览器打开 **[https://board.example.com/](https://board.example.com/)**。
2. 选择 **「登录」**。
3. 输入上一节设置的序程用户名和密码。
4. 点击 **「进入看板」**。
5. 在页面上方选择你的项目，在 **「任务清单」**查看进度；在 **「手机连接」**查看电脑连接状态与最近同步时间。

**成功标志：**手机显示和电脑同步的同一个项目、已有任务及最新进度。

以后可以直接用账号登录，不必每次寻找管理员令牌或生成配对码。账号登录不会返回一个必须再输入的配对码。

## 4. 电脑：确认连接，或接入另一台电脑

### 已连接的电脑

打开桌面版序程 → **「手机连接」**，确认「连接状态」显示 **「已连接」**，地址为 `https://board.example.com`，最近同步时间持续更新即可。原来的连接会在你绑定账号后继续有效。

### 新电脑或尚未连接的电脑

1. 打开桌面版序程，新建或导入本机项目；要运行 Codex，项目需对应这台电脑上的实际目录。
2. 进入 **「手机连接」** → **「连接到自己的服务」**。
3. 按以下内容填写。

| 界面字段 | 填写内容 |
|---|---|
| 服务器地址 | `https://board.example.com` |
| 连接方式 | 选择「账号密码」 |
| 用户名 | 你的序程用户名 |
| 密码 | 你的序程密码 |
| 允许同步的项目 | 勾选希望手机查看和操作的本机项目 |

4. 点击 **「连接手机端」**。
5. 等待状态变为 **「已连接」**，再到手机网页刷新并选择项目。

桌面主窗口管理的是本机项目；网页显示的是账号下已授权同步的项目。登录不会自动下载代码，也不会把另一台电脑的执行目录和 Codex 会话迁移过来。

## 5. 手机：新建对话，让电脑上的 Codex 做事

开始前，项目电脑应开机、联网、序程运行；Codex 已登录，序程「接入与插件」中的连接检查正常。电脑休眠或序程退出后，手机仍可能看到旧进度，但不能开始新的执行。

1. 手机网页上方选择要操作的项目。
2. 点击导航中的 **「对话」**。
3. 在 **「已有对话」**选择 **「新对话」**。
4. 填写 **「对话标题」**和 **「告诉 Codex 要做什么」**。
5. 点击 **「创建并开始」**，等待电脑回执和「对话输出」。

第一次可以使用这个便于核对的例子：

```text
标题：了解项目
需求：请阅读这个项目，简要说明入口文件、主要功能和测试命令。先只说明，不修改文件。
```

确认输出能正常返回后，可以在同一对话发送具体修改要求。下次进入时，从「已有对话」选择原任务，填写 **「继续说明需求」**，点击 **「发送消息」**。执行中可点击 **「暂停执行」**，等待暂停回执。

**成功标志：**电脑出现对应任务，手机收到该会话的回复或工具输出；输出在页面打开时约每 2 秒刷新。结果显示「已提交」「未知」或「等待授权」时，不等于已经完成，应先核对回执。

当前显示的是序程管理或已绑定到任务的 Codex 会话，不会自动列出电脑上所有聊天软件里的历史对话。已有任务未绑定执行会话时，需在桌面端先完成绑定。

## 6. 可选：用配对码连接，不输入账号密码

**配对码在已经以管理员身份登录的服务器网页里生成。** 桌面端「手机连接」主要负责连接服务器；网页中的同名页面负责生成配对码与管理设备。

### 给手机生成配对码

1. 在电脑浏览器登录服务器网页，进入 **「手机连接」**。
2. 找到 **「生成一次性配对码」**。
3. 「连接权限」选择 **「查看和操作」**；如果只需要看任务进度，选择 **「仅查看」**。
4. 在「授权项目」勾选要授权的项目。
5. 「有效时间（秒）」可保留默认 `600`，即 10 分钟。
6. 点击 **「生成配对码」**，复制显示的代码。
7. 手机打开服务器网页登录页 → **「其他连接方式」** → **「手机配对码」**，输入代码，点击 **「进入看板」**。若手机已经登录，先到「账号」退出再换连接方式。

配对码只能使用一次，过期或已经使用就需要重新生成。「仅查看」可看任务进度，不能读取完整对话或发送执行要求。

### 给电脑生成配对码

在服务器网页选择 **「项目电脑」**权限，为目标电脑的项目生成代码；目标桌面程序进入「手机连接」→「一次性配对码」，填写服务器地址、代码并选择匹配的本机项目，点击「连接手机端」。项目尚未出现在网页时，可在生成页面的「项目 ID」字段填入目标桌面项目的 ID。

对自己的新电脑，直接使用第 4 节的账号密码流程通常更方便。

## 7. 常见问题

| 遇到的情况 | 处理方式 |
|---|---|
| 注册成功，但看不到原来的任务 | 新注册的账号进入了空空间。先退出，再用原管理员令牌进入原空间并绑定账号。如果新用户名已被占用，需要换一个未使用的用户名；当前没有合并两个空间的入口。 |
| 找不到「为当前空间设置账号」 | 在服务器网页中用原 owner 管理员令牌进入；普通配对设备没有这个权限。已经绑定账号的空间无需重复设置。桌面端不提供这个绑定表单。 |
| 电脑已连接，但手机没有项目 | 确认是同一个服务器地址、同一个空间；桌面端勾选了该项目；手机刷新后选择正确项目。配对登录还需确认代码授权了该项目。 |
| 手机显示「电脑离线」 | 在电脑检查序程是否运行、是否休眠、网络是否正常；到桌面「手机连接」检查状态。恢复后等待同步，再发送新消息。 |
| 「创建并开始」或「发送消息」不可点 | 检查电脑在线、项目已选择、手机具有操作权限；已有请求等待回执时，先等它完成或核对结果。 |
| 任务显示「等待授权」 | 到项目电脑核查 Codex 登录及执行状态。当前手机网页没有额外审批放行入口；不要反复点击创建。 |
| 提交结果「未知」 | 先刷新任务和对话输出，到电脑核对是否已经开始。确认后再决定下一步，避免重复执行。 |
| 密码不对或忘记密码 | 核对用户名、服务器地址和输入。当前没有邮箱找回；保留原管理员令牌，并联系服务维护者处理，不要通过反复注册尝试取回原空间。 |
| 配对码无效 | 检查手机/项目电脑权限类型是否匹配、是否过期或已使用；重新生成对应类型的代码。 |

## 8. 改密码与撤销设备

账号登录后，网页 **「账号」→「修改密码」**可以更新密码，随后各浏览器需重新登录。

已配对设备不会因为改密码自动失效。设备丢失或不再使用时，在服务器网页 **「手机连接」→「已配对连接」**找到对应设备，点击 **「撤销」**。

公网部署应通过 HTTPS 加密传输，并保持服务器防火墙开启；服务端管理员仍可读取服务器保存的任务和对话。具有操作权限的设备可以让 AI 修改授权项目，也可能请求 AI 读取电脑上的其他可读内容，因此只给信任的设备授予操作权限。

更多会话同步范围和安全边界见 [账号与远程对话](accounts-and-conversations.md)，当前验证结果见 [v0.3.0 验证记录](accounts-conversations-validation.md)。

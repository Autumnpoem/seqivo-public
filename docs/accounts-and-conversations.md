# 账号与远程 Codex 对话

首次使用请按[账号接入指南](account-setup.md)逐步操作，其中包含原空间绑定、手机登录、电脑连接、配对码和常见问题。

Hub 是自托管服务。示例地址 `https://board.example.com` 请换成你自己的 HTTPS 地址。项目电脑负责运行 Codex；手机和其他电脑通过 Hub 查看已授权项目、发送自然语言消息并查看可见输出。此处的“像 CLI 一样对话”是向 Codex 提交自然语言任务，**不是在手机上执行操作系统 shell 命令**。

## 开始使用

**新用户：**打开 Hub 网页，选择“注册”，设置用户名和密码。注册会创建独立的空空间，不会自动取得其他人的项目。用户名为 3–40 位字母、数字、下划线、句点或短横线，以字母或数字开头；密码为 12–128 个字符。此后在电脑和手机上用同一地址和账号密码登录。

**已有 Hub owner：**先用原来的 owner 访问令牌登录**已有空间**，进入“账号”→“为当前空间设置账号”，设置用户名和密码。这个步骤将账号绑定到当前空间，保留已有项目、任务和已配对设备。不要先点“注册”去建立另一个空空间。每个空间只能绑定一个账号。

在项目电脑的“手机连接”页，填写 Hub 地址、账号密码，勾选至少一个允许同步的项目，然后连接。也可以选择一次性“项目电脑”配对码。电脑需要保持开机、看板服务运行并能连接 Hub；新版对话功能要求项目电脑升级到包含该功能的版本。Hub 不会主动连接项目电脑。

在手机上打开同一个 Hub 地址，用账号密码登录。也可由 owner 在“手机连接”生成限定项目和权限的一次性配对码，在手机选择“手机配对码”进入。仅查看权限可看任务进度，不能读取完整对话、发消息或控制任务；操作权限只作用于获授权项目。配对码有期限且只可使用一次，失去设备后到“已配对连接”撤销。

## 对话与状态

打开“与 Codex 对话”，选择已同步的项目，填写标题和第一条消息即可在项目电脑的本地目录创建任务及 Codex 会话。选择已有对话可继续发送消息，也可暂停正在执行的任务。所有远程操作都受项目授权和本地任务版本检查；电脑离线时不能新发对话消息。发送后的“已提交”“等待授权”“未知”等状态不等于 Codex 已完成。结果未知时先核对任务和输出，避免重复提交。

可见对话输出在网页显示时约每 2 秒更新一次；实际速度取决于电脑运行、网络和模型服务。Hub 只从已选项目同步手机请求查看的最多 5 项任务的对话内容，并限制每项输出的长度。可见的 AI 回复与工具输出可能包含代码、文件内容或生成的秘密，应像项目文件一样保密。隐藏推理不会共享。项目摘要等自由文本也不是自动秘密扫描结果，输入秘密前请考虑同步范围。

## 账号与安全

浏览器登录使用有效期 7 天的 `HttpOnly`、`SameSite=Strict` 会话 cookie；HTTPS 部署还设置 `Secure`。退出登录撤销当前会话；在“账号”修改密码会撤销该账号的全部浏览器会话，需要重新登录。**修改密码不会自动撤销已配对的电脑或手机**；如设备遗失，请在“已配对连接”逐个撤销。旧 owner 访问令牌仍按旧凭据规则管理。

当前没有邮箱找回或多因素认证。请保管密码和原有 owner 令牌；文档没有提供密码找回命令。公网访问必须使用 HTTPS。传输加密不等于端到端加密：Hub 服务端、可访问数据库及备份的管理员能读取同步的任务和对话内容。参见 [安全说明](../SECURITY.md) 与 [部署指南](deployment.md)。

本轮 167 项单元/集成、Chromium 与 WebKit 手机视口流程通过；真实 Codex 在临时项目中的两轮文件修改与回传也已通过。公网 HTTPS 账号与隔离已实测；实体手机和其他系统的原生体验仍待验证。详见[本轮验证结果](accounts-conversations-validation.md)。

新建对话为看板创建的独立 Codex 会话启用项目目录写入，关闭该回合的网络访问和额外临时目录写入，不改动全局模型、审批或沙箱配置；已有外部会话沿用原权限。当前 Codex 版本的写入沙箱不能限制全部文件读取：拥有操作权限的人可以通过 AI 请求读取电脑上的其他可读文件。只将操作权限授予你信任的设备和人员；不同 Hub 账号的数据隔离不等于本机操作系统的读取隔离。需要超出权限的操作会被停止，当前网页没有审批放行入口。

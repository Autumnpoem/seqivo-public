On first launch, enter the Hub's HTTPS origin, such as `https://example.com`. The app remembers only this address in app-private preferences. Sign in with an account or a pairing code on the Hub page. Account sessions use the Hub's normal secure cookie; access-token mode uses the website's session storage and may require sign-in again after the Android process is killed. The app does not copy tokens or passwords into native storage.

The app accepts only an HTTPS origin with no path, user information, query, or fragment. Android validates the server certificate. The WebView blocks cleartext and mixed content, disallows file/content access and third-party cookies, and keeps top-level navigation on that origin. It has no JavaScript bridge. Use the overflow menu to change the server address. The system back button follows WebView history when available; otherwise it leaves the app. The keyboard resizes the page, and the WebView pauses and resumes with the activity.

## Build

For a repeatable local debug deliverable, use `scripts/build-android.mjs` with an explicit version code and `JAVA_HOME`/`ANDROID_SDK_ROOT`; it writes only the ordinary signed debug APK to ignored `.runtime/android/deliverables/`. The script runs unit tests, builds debug and release, checks the APK identity and signature, and rejects a test CA or network-security override in normal APKs. The release output is unsigned and is not copied as a deliverable. The script clears `SEQIVO_ANDROID_DEFAULT_ORIGIN` and `SEQIVO_ANDROID_TEST_CA` in its Gradle child process so a private endpoint or fixture CA cannot enter this build. See the Chinese guide for the exact command and upgrade rules.

Install JDK 17, Android SDK Platform 35, Build Tools 35.0.0, and Gradle 8.9. Set `JAVA_HOME` and `ANDROID_SDK_ROOT`, then run from `android/`:

```sh
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

The repository currently uses an external Gradle installation, not a checked-in wrapper. From the repository root, `pnpm android:build --version-code 1 --gradle /path/to/gradle-8.9/bin/gradle` invokes the checked deliverable script described above. `pnpm android:smoke` invokes the isolated-emulator checks below; it is a test command and clears that test app's data on the designated AVD.

The installable debug APK is `android/app/build/outputs/apk/debug/app-debug.apk`. Android 8.0 (API 26) or later is required. The build normally opens the address entry screen. For a private local build only, `SEQIVO_ANDROID_DEFAULT_ORIGIN` may supply an HTTPS origin at build time; it will be embedded in that APK, so do not use it for a public artifact. No private server address or credential belongs in tracked source.

The default `versionCode` is 1. For an upgrade build, pass a positive integer of up to nine digits, for example `-PseqivoVersionCode=2`. Keep the same application ID and signing key for an in-place upgrade. This property does not put a server address or test certificate into a normal build.

On launch, a native loading indicator covers the WebView until the Hub renders content. If that takes 45 seconds, the app shows a connection error with a manual **重试** button; it does not automatically repeat a request. A page-load or certificate error also offers a manual retry. This loading state is native and appears even before the website can render.

The native server setup, loading, and connection-error screens follow Android's system light or dark mode, including the status and navigation bars. The Hub webpage has its own appearance setting, so its theme can differ from the native screens. The native setup and error screens scroll when a large font or landscape orientation leaves too little room for their buttons.

The debug APK is signed with Android's local debug key and is intended for local installation and testing. A production release needs an owned signing key, release process, and physical Android device verification. This repository's browser viewport tests do not establish real-device behavior. On a phone, verify account login, task/inbox refresh, conversation send and output, pause/continue permissions, keyboard, back navigation, background/foreground recovery, network loss, and certificate rejection against the intended Hub.

## English

The current implementation records each plan’s authorized goal and next step, then rechecks that intent while waiting for quota and before dispatch. A changed goal or next step, or a legacy plan without this authorization, stops and requires an explicit restart. Criteria and approach are not separately included in the authorization snapshot. The UI separates a proposed action from the saved authorized action and shows the next check and stop reason. Only verified quota failures from the same automatic plan are counted once per command; the plan stops after two. An explicit restart resets the count. A successful automatic turn is still submitted for human review and disables the plan rather than starting another turn automatically.

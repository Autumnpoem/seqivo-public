## Core additions (Root)

Store APIs: history({projectId?,taskId?,afterSeq?,limit?}) returning {events,cursor}; checkpoint journal with complete changed entities and metadata sufficient for projection rebuild. Migration snapshots existing state once; new commits append transactional journal entries. rebuild projections transactional; never executes plugins/commands. export/restore archival data with schema/version/digest and bounds; restore only explicit owner action and stopped automation.

GET /api/history?taskId=&afterSeq=; GET /api/backup returns archive JSON; POST /api/backup/restore {archive,confirm:true}; POST /api/maintenance/replay {confirm:true}. UI download/import uses these endpoints. GET /api/plugins lists descriptors incl supported config schema/permissions; generic actions same existing routes.

Task optional sourceConversation={provider,conversationId,label} for attribution (cannot authorize controls); existing conversationId remains explicit user control binding. Core accepts sourceConversation in create/report for progress attribution only; update cannot alter control binding. UI filter all/unbound/source conversation and shows count in selected scope.

## Remote node interface

Integration exports async createRemoteLink({dataDir,getState,request,emit,now?}) from server/remote-client.mjs. Returns {state(), configure({url,pairingCode,projectIds}), disconnect(), close()}. configure consumes one-time pairing code; credentials persisted 0600 but never returned from state. state={status:'disconnected'|'connecting'|'connected'|'offline'|'revoked'|'error',url,nodeId?,lastSyncAt?,lastError?,projectIds:[]}. Root exposes GET /api/remote; POST /api/remote/connect; POST /api/remote/disconnect. Credentials and queue receipts survive restart; no auto re-enrol.

getState returns actual BoardState. Only explicitly selected projectIds may sync. Strip local directories, plugin configs, runtime credentials, full chat/code. Nodes send authoritative project/task snapshots + sequence/ownership epoch. Hub does not dual-write node state. request(method,path,body) is a local core callback; remote client must map allowlisted actions to fixed task routes after selected-project/revision/expiry/epoch checks. Never execute arbitrary shell, URL or caller-supplied path.

## Hub phone API

Hub serves same dist assets and GET /api/state (same BoardState; sanitized projections; connection.mode='hub', lastSeen/offline; capabilities desktop=false,remote=true, role viewer/controller). Phone submits task continue/pause/update/evidence/review as durable commands, not optimistic local success; returned {commandId,status:'queued'|'running'|'paused'|'unknown'|'expired'|'failed',...}. GET /api/commands/:id reports result. Viewer cannot submit. Per-project grant required both when enqueueing and before delivery/claim. Commands bind node, ownership epoch, task revision, expiry and stable commandId; duplicate changed payload is conflict. A node persists accepted command before external send, never blindly retries an unknown external result. Pause same bound-turn rules as local. Revocation denies further authenticated requests/delivery, cancels unclaimed pending commands; does not claim already executing AI stopped.

Hub bootstrap/admin HTTP distinct from browser tokens: tenants isolated in all data, pairing codes and commands. Short-lived single-use pairing codes scoped to tenant, role (node/viewer/controller) and project grants. Explicit tenant-owner grants; no public signup or default credentials. CLI bootstrap outputs token FILE location only. TLS required outside loopback, bounded bodies/rates/queues, token hashing, no query-string secrets, no task content executed as instructions by Hub. Pairing API paths/details owned by integration child; document exact routes for UI and deployment after initial sketch.

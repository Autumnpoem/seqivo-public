# Mac Rust crates without a standalone license file in their crate archive

The 18 exact versions below are in the Mac `aarch64-apple-darwin` normal-dependency tree. Their local crates.io archives have no root `LICENSE`, `LICENCE`, `NOTICE`, or `COPYING` file. The declared license is recorded in [mac-rust-dependencies.csv](mac-rust-dependencies.csv); each archive's `.cargo_vcs_info.json` supplies the pinned repository commit used here. The upstream texts identified below are copied verbatim with source URLs and SHA256 values in [mac-rust-upstream-license-texts.txt](mac-rust-upstream-license-texts.txt). This does not assign a license that the crate itself did not declare.

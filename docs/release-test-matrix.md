来源为 本机原始项目的 23 项任务（下表保留验收标准；个人任务记录不入库）（2026-09-26）。这里的“通过”只表示该条标准在注明的范围内有可重现证据，**不是用户的人工验收结论**；“部分”表示已验证子条件但整条标准仍有缺口，“未验证”表示缺少必需环境或尚未执行，“失败”留给已观察到的反例。`executionStatus` 和 `acceptanceStatus` 未由这次审计改写。当前结论：**11 通过、11 部分、1 未验证、0 已证实失败**，还不能据此宣布三系统正式发布就绪。

上述浏览器流程验证的是界面、真实本地服务与 Hub 的可观察行为；`board` 中的“人工验收”是测试角色操作的状态流转，不能代替用户对真实项目的内容验收。后续代码或打包结果改变后，应重跑受影响的测试并更新本矩阵。

仓库内的可重现测试入口为 `pnpm test`、`pnpm build`、`node tests/e2e/{board,features,remote,verification}.mjs`（分别运行），WebKit 设置 `TEST_BROWSER=webkit`。真实模型测试另需 `TUIJIN_REAL_PROVIDER_TEST=1` 显式启用。最新脱敏运行摘要见 [release-test-results.json](release-test-results.json)；原始日志、截图、任务数据库及模型会话标识保留在本机，不随源码上传。

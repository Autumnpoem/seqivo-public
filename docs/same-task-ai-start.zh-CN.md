# 在原任务中开始 AI

此功能允许从任务详情启动一个尚未绑定会话的任务。启动后，任务 ID 不变；进度、证据和后续验收仍归属原任务。

## 使用步骤

1. 在手机或 Hub 打开目标项目的任务详情。
2. 对“待开始”、尚未绑定 Codex 会话的任务，点 **让 AI 开始**。
3. 查看任务目标和验收标准，填写明确的启动说明。
4. 点 **让 AI 开始此任务**。仅打开表单不会发送请求；明确提交后项目电脑才会开始处理。
5. 等待回执和任务状态更新。输出会显示在该任务的对话区域，可从原任务继续查看进度与证据。

“新建对话”仍会创建独立任务和会话，不会替代或修改当前任务。开始已有任务则沿用其原 ID，不会新建任务。

## 使用条件与待确认结果

- 仅适用于待开始、尚未绑定执行会话的 Codex 任务。
- 手机需在线，且连接到支持此操作的项目电脑；需要有操作权限。查看者、离线连接或不支持该能力的旧版电脑会显示不可用状态和原因。
- 如果页面提示启动结果未知或仍在核实，**不要再次提交**。先在同一个原任务中查看状态和回执；确认原请求已处理后再继续。未知状态会保留原请求锁定，避免重复启动。
- 提交失败时草稿会保留；收到匹配的成功回执后，才会清除已提交草稿。

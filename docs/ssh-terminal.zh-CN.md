## 产品目标

Mac 和手机都能连接用户自行添加的 SSH 服务器或电脑，进入 Shell，选择目标机器上已有的 tmux 会话。目标机器无需安装序程，也不要求关联 AI 任务。序程现有的本机远程控制与 AI 接管能力继续保留为独立入口。

### 正常流程

1. 终端首页显示「服务器」「电脑」两类主机，可搜索、分组、添加、编辑、移除。
2. 添加连接时填写名称、IP／域名、端口、系统用户名，以及密码或私钥，点击「保存并连接」。用户名和密码是目标机器的 SSH 登录信息，与序程账号不同；密码框直接显示，不必先勾选保存。只有勾选「保存登录凭据」才会记住密码／私钥。
3. 首次连接显示目标 SSH 主机公钥的 SHA-256 指纹；用户核对后才发送登录凭据。指纹变化时单独提示，不能静默接受。
4. 连接后主体为终端。底部打开目标账号、目标 tmux 服务的会话列表，支持选择已有会话、新建会话、设为默认和普通 Shell。
5. 每个主机独立保存默认会话。临时切换不修改默认；下次连接进入默认会话。默认会话结束或服务器身份变化时要求重新选择，不自动创建同名替代品。
6. 网络断开、手机切后台后不会重发输入。tmux 的程序留在目标机器上；恢复连接读取目标主机现有现场。普通 Shell 的进程是否保留由目标 SSH 服务决定，不能承诺等同于 tmux。

### 两种连接路径

| 客户端 | SSH 从哪里发起 | 主机资料存放 |
| --- | --- | --- |
| Mac 桌面 | 这台 Mac 直接连接目标主机 | 本机主机库 |
| Android App／手机网页 | 已登录的序程 Hub 连接目标主机 | 当前账号主机库 |
| Mac 浏览器打开 Hub | 与手机使用同一账号主机库 | 当前账号主机库 |

手机连接任意服务器不依赖个人 Mac 开机。目标必须能被所选连接端访问；公网服务器不能直接访问家里无路由的内网电脑。高级设置支持通过已有 SSH 主机作为一层跳板机，目标和跳板分别核对指纹。当前不自动同步桌面本机主机库与 Hub 账号主机库，也不会暗中上传本机凭据；需要同一份主机列表时在 Mac 浏览器与手机登录同一 Hub。

Hub 默认禁止直接连接回环、内网和链路本地等地址，防止公开注册账号访问 Hub 内网资源；本机连接允许局域网。专用部署的内网网关属于管理员配置范围，不能由普通账号在网页中解除此限制。

## 接回 Termius 中正在做的工作

1. 在序程添加 Termius 使用的**同一台主机、同一个 SSH 用户**，使用该账号的密码或私钥登录。
2. 打开终端底部的「会话」：列表来自目标账号的真实 tmux。选中原会话，即可继续它里面的程序。
3. 对常用会话点「设为默认」，之后每次主动连接这台主机都会打开它。临时切换不会修改默认。
4. 如 Termius 原来用 `tmux -L 名称`，在连接的「高级设置 → tmux 服务名称」中填同一名称；普通 `tmux ls` 使用 `default`。

Termius 标签页本身不是 tmux 会话，普通 SSH Shell 也不会自动出现在列表里。当前支持默认 socket 和 `tmux -L` 命名 socket，不支持导入 Termius 的凭据库或任意 `tmux -S` 路径。目标上尚无 tmux 时，可以打开普通 Shell，再按目标系统的方式安装／启动 tmux。

## 界面边界

- 普通 SSH 首页不显示 AI 执行权、受管目录写入者和待批准设备。
- 「本机与已绑定电脑」入口保留原本机／远程电脑控制流程和安全校验。
- 普通 SSH 不宣称阻止目标机器上其他终端、编辑器或 AI 同时修改文件。
- 「服务器」「电脑」是用户分类，不限制操作系统。目标需提供兼容的 SSH 服务；tmux 列表功能需要目标账号可执行 tmux。Windows 普通 SSH Shell 与 WSL 中的 tmux 是不同环境。

## 凭据和会话安全

- 密码、私钥和口令默认只在本次连接中使用，不写入浏览器本地存储，不放进 URL、任务记录或日志。
- 用户明确勾选保存时，凭据使用 AES-256-GCM 加密落盘，关联账号和主机 ID。密钥与凭据文件仅当前系统用户可读写。主机 API 只返回「是否保存」，不返回密码和私钥。
- 这不是端到端加密或硬件密钥库。连接从 Hub 发起时，Hub 在内存中处理 SSH 凭据与终端内容；拥有服务器系统权限的管理员能够读取。只在可信的私用服务保存凭据。
- Hub SSH 要求账号登录。看板 viewer、reporter、node 或项目配对令牌不能调用通用 SSH。WebSocket 使用短时、一次性票据并绑定原登录会话；退出或撤销会话后连接关闭。
- 使用 HTTPS／WSS 连接 Hub，Hub 到目标使用 SSH。主机指纹不匹配时不自动登录。凭据失败不自动循环重试。
- 输入绑定当前终端代次与递增序号，不提供断线后自动补发。输出有缓存／速率边界，慢客户端断开不终止目标 tmux 服务。
- 移除主机只删除连接资料和已保存凭据；不执行远程删除或 kill-session。
